# HomeBaked Delights 🍰
A bakery-themed e-commerce website built using HTML, CSS and JavaScript.

## About the Project
HomeBaked Delights is a web-based bakery storefront that allows users to explore bakery products, select flavours, manage their shopping cart and view pricing details.

## Features
- Product listings and flavour selection
- Interactive shopping cart
- Quantity management
- Dynamic price calculation
- Coupon functionality
- Login interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html – Website structure
- style.css – Styling and layout
- script.js – Interactive functionality

## Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
